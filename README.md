- **Technologies Used:**

  ![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

### 📌 **C.H.R.I.S. — Cognitive Humanoid Reasoning Interactive System**
- **Description:**
  Open-source AI VTuber project focused on creating an autonomous and interactive virtual streamer. Instead of relying only on an LLM prompt, C.H.R.I.S. explores a persistent agent architecture built around identity, memory, personality, values, goals, relationships, beliefs, emotions, and a model of the world.

  The project is inspired by research such as **Generative Agents: Interactive Simulacra of Human Behavior** and explores how an artificial agent can maintain continuity and develop behavior that changes according to its internal state and experiences.
- **Technologies Used:**

  ![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
  ![OpenAI](https://img.shields.io/badge/OpenAI-412991?style=for-the-badge&logo=openai&logoColor=white)
  ![Google Cloud](https://img.shields.io/badge/Google_Cloud-4285F4?style=for-the-badge&logo=google-cloud&logoColor=white)
  ![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)

  - VTube Studio
  - YouTube / Twitch
  - OBS
  - Speech-to-Text / Text-to-Speech

- **Key Features:**
  - 🧠 Persistent identity and autobiographical memory architecture
  - 🎭 Personality, values, beliefs, goals, relationships, and emotional state
  - 💭 Memory and reflection inspired by Generative Agents research
  - 🗣️ Speech-to-Text and Text-to-Speech interaction
  - ☁️ Designed to run locally or in the cloud
  - 🎥 Integration with VTuber streaming workflows
  - 🔓 Open source
- **Repository:**
  [AmiyaMihari/C.H.R.I.S.](https://github.com/AmiyaMihari/C.H.R.I.S.)
- **Status:**
  In development 🚧
